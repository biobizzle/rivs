# RIVS — Immersive Interior Design

This repository is being prepared for the RIVS cinematic interior-design website.

The experience is a static, responsive front-end with architectural scroll storytelling, CSS 3D perspective, and a restrained Liquid Glass-inspired interface.

Implementation is developed on a feature branch and reviewed through a pull request before merging. Demo media from externally sourced reference videos is not approved for public redistribution or production deployment.
